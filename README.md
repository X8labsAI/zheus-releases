# Zheus AI para computador

Instaladores oficiais do Zheus AI.

**[Baixar a última versão](https://github.com/X8labsAI/zheus-releases/releases/latest)**

| Computador | Arquivo |
|---|---|
| Mac com Apple Silicon (M1, M2, M3, M4…) | `Zheus-AI-<versão>-arm64.dmg` |
| Mac com Intel | `Zheus-AI-<versão>-x64.dmg` |
| Windows | `Zheus-AI-<versão>-x64.exe` |

Depois de instalado, o app se atualiza sozinho.
